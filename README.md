# Who Am I? — Guess Together

## เปิดเกมในเครื่อง
1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. รัน `npm start` หรือ `node server.js`
4. เปิด `http://localhost:3000` ในเบราว์เซอร์

## ทดสอบ
- กด **สร้างห้อง** แล้วเลือก **โหมดทดสอบคนเดียว** เพื่อทดลองหน้าต่างและ flow เบื้องต้น
- หากเล่นหลายคน ให้สร้างห้องอย่างน้อย 2 คนแล้วส่งรหัส 6 หลักให้เพื่อน
- ถ้าเพื่อนอยู่ใน Wi-Fi/LAN เดียวกัน ให้เปิดเว็บผ่าน IP ของเครื่องที่รันเซิร์ฟเวอร์ เช่น `http://192.168.1.10:3000` และอนุญาต Node.js ผ่าน Windows Firewall หากถาม

## หมายเหตุ
- ห้องและสถานะเกมเก็บในหน่วยความจำของเซิร์ฟเวอร์ การรีสตาร์ตเซิร์ฟเวอร์จะล้างห้องทั้งหมด
- การเล่นผ่านอินเทอร์เน็ตสาธารณะต้องนำ Node.js server ไป deploy บนโฮสต์ที่เข้าถึงได้จากอินเทอร์เน็ต
- ไม่มีแชท ไมค์ หรือตัวจับเวลาในเกม

## ทดลองเล่นจากมือถือ
1. ให้มือถือและคอมที่รันเซิร์ฟเวอร์เชื่อม Wi-Fi วงเดียวกัน
2. บนคอม เปิด Command Prompt แล้วพิมพ์ `ipconfig`
3. ดู `IPv4 Address` ของการ์ด Wi-Fi/Ethernet ที่กำลังใช้งาน
4. บนมือถือเปิด `http://IP-ของคอม:3000` เช่น `http://192.168.1.10:3000`
5. หากเข้าไม่ได้ ให้ตรวจ Windows Firewall และอนุญาต Node.js เฉพาะเครือข่าย Private ที่เชื่อถือได้

หน้าเว็บปรับขนาดตามจอมือถือ ปุ่มออกแบบให้แตะได้ง่าย และหน้าต่าง/ฟอร์มเลื่อนดูได้เมื่อคีย์บอร์ดมือถือเปิดอยู่ การเปิดให้เล่นผ่านอินเทอร์เน็ตจากคนละเครือข่ายยังต้อง deploy เซิร์ฟเวอร์ก่อน

## ลำดับผู้เล่นในเกม
- หลังผู้เล่นทุกคนตั้งคำเสร็จ เซิร์ฟเวอร์สุ่มผู้เล่นเริ่มต้นด้วย `crypto.randomInt`
- ลำดับตำแหน่งรอบวงใช้ตามลำดับผู้เล่นในห้อง โดยตำแหน่งถัดไปตามเข็มนาฬิกา
- เมื่อกดผ่านหรือส่งคำตอบ ระบบขยับไปยังผู้เล่นถัดไปตามเข็มนาฬิกา และข้ามคนที่ตอบจบแล้ว (WINNER/LOSER)

## ระบบเตรียมพร้อมและเล่นซ้ำ
- ห้องจะยังไม่เริ่มจนกว่าจะมีผู้เล่นครบตามจำนวนที่ตั้งไว้ และผู้เล่นทุกคนกด **เตรียมพร้อม**
- หากผู้เล่นคนใดกดยกเลิกพร้อมระหว่างนับถอยหลัง 3–2–1 จะหยุดนับและกลับไปรอใหม่
- เมื่อเกมจบ ระบบจะกลับห้องรอเดิม แสดงอันดับรอบล่าสุด และยกเลิกสถานะพร้อมของทุกคน
- เริ่มรอบถัดไปได้เมื่อผู้เล่นครบและทุกคนกดเตรียมพร้อมอีกครั้ง
- โหมดทดสอบคนเดียวก็ต้องกดเตรียมพร้อมก่อนเริ่มเช่นกัน
