# Who Am I? — Guess Together

เกมทายคำแบบเล่นหลายคน พร้อมห้องรอ โปรไฟล์ผู้เล่น คำใบ้ และการโหวตคำตอบ

## เปิดเกมในเครื่องด้วย Node.js

1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. รัน `npm start`
4. เปิด `http://localhost:3000`

การรันแบบ Node.js เดิมเก็บห้องในหน่วยความจำ จึงล้างห้องเมื่อรีสตาร์ตเซิร์ฟเวอร์

## เตรียมสำหรับ Cloudflare Workers

โปรเจกต์มีไฟล์ Worker แยกจากเซิร์ฟเวอร์ Node.js เดิม:

- `src/index.mjs` — Worker API และ Durable Object สำหรับสถานะห้อง
- `wrangler.jsonc` — ผูก static assets จาก `public/` และ SQLite-backed Durable Object
- `public/` — หน้าเว็บ CSS และ JavaScript
- `server.js` — เซิร์ฟเวอร์ Node.js สำหรับรันในเครื่องแบบเดิม

ห้องและข้อมูลผู้เล่นของ Worker ถูกบันทึกผ่าน SQLite-backed Durable Objects เพื่อให้สถานะยังอยู่เมื่อ Worker ถูกหยุดแล้วเริ่มใหม่

### ทดสอบ Worker ในเครื่อง

1. ติดตั้ง dependencies ด้วย `npm install`
2. รัน `npm run dev`
3. เปิด URL ที่ Wrangler แสดงใน Terminal
4. ทดสอบสร้างห้อง เข้าห้อง พร้อมเล่น ตั้งคำ ตอบ และโหวต

### Deploy ผ่าน Cloudflare Dashboard

1. เชื่อม GitHub repository นี้กับ Workers & Pages
2. ใช้ Root directory เป็นรากของ repository (ปล่อยว่างถ้าหน้าตั้งค่าให้เลือกโฟลเดอร์)
3. Build command ปล่อยว่างได้
4. Deploy command ใช้ `npx wrangler deploy`
5. ตรวจชื่อ Worker และไฟล์ `wrangler.jsonc` ก่อนกด Deploy

อย่าเลือก Pages-only หรืออัปโหลดเฉพาะ static files เพราะระบบห้องต้องใช้ Worker และ Durable Objects

## ฟีเจอร์เกม

- สร้างห้อง 2–20 คน หรือโหมดทดสอบคนเดียว
- แชร์รหัสห้อง 6 หลัก
- ทุกคนต้องกดพร้อมก่อนเริ่มนับถอยหลัง 3–2–1
- ตั้งคำหรือรูปให้ผู้เล่นถัดไป โดยซ่อนคำของตัวเอง
- ผู้เล่นอื่นตอบ ใช่ / ไม่ใช่ / อาจจะ และผู้ทายส่งคำตอบอิสระ
- ผู้เล่นคนอื่นโหวต ถูก / ผิด; คะแนนเสมอนับเป็นผิด
- แสดงอันดับรอบล่าสุดและกลับไปห้องรอเพื่อเริ่มรอบใหม่
- แก้ชื่อและรูปโปรไฟล์ได้ในล็อบบี้

## ข้อควรรู้เกี่ยวกับแพ็กเกจฟรี

Cloudflare Workers Free และ Durable Objects Free มีโควตารายวันและข้อจำกัดการใช้งาน การ polling ของหน้าเกมถูกตั้งไว้ประมาณทุก 2.5 วินาทีเพื่อลดจำนวนคำขอ แต่ไม่รับประกันว่าใช้งานได้ไม่จำกัด หากมีผู้เล่นออนไลน์จำนวนมากหรือนานมากอาจแตะโควตาฟรีได้

## หมายเหตุ

- ไม่มีแชท ไมค์ หรือระบบจับเวลาคำถามในเกม
- หน้าเว็บรองรับมือถือ และปรับรูปโปรไฟล์เป็น JPEG ขนาดเล็กก่อนส่ง
- การทดสอบในเครื่องไม่ใช่การ Deploy จริง ต้องกด Deploy จาก Cloudflare Dashboard เพื่อเผยแพร่
